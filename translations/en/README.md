# Английский текст уроков

Здесь лежит **читаемая версия для вычитки** — английская грамматика первых
уроков обоих курсов:

- `greek/lesson-01..03.md` — из `data/lessons.js` (греческий, уроки 1–3);
- `hebrew/lesson-01..03.md` — из `data/hebrew-lessons.js` (иврит, главы 1–3).

Текст, который показывает приложение, лежит не здесь, а в `data/lessons.en.js` и
`data/hebrew-lessons.en.js` — он собран из тех же словарей переводов и устроен
как оверлей над русскими данными. Эти файлы — образцы его формулировок: по ним
удобно сверять терминологию, не открывая длинные строки в данных.

## Что уже в приложении

Английский режим: карточка «Язык» в настройках, ключ `app_lang`. По-английски
открывается **материал всех уроков обоих курсов** — 16 уроков греческого и
12 глав иврита:

- заголовок урока и грамматика;
- словарь: значение каждого слова, а если статья несёт пометку по-русски
  («Fut. от διώκω»), то и она;
- таблицы форм: подписи осей («Падеж», «Лицо», «Ед.ч.», «Мн.ч.», роды) и
  колонка «Перевод»;
- чтение ивритского слова — одна транслитерация учебника без русской половины
  («dāḇār» вместо «давáр (dāḇār)»).

Урок без перевода по-прежнему открывается по-русски с пометкой: механизм нужен
уроку, который добавят в данные завтра.

## Чего здесь нет

- **Упражнений.** Это не текст, а проверяемые ответы: в английском нужен свой
  набор допустимых формулировок и своя сверка (`keywordsMatch`). Поэтому вкладки
  упражнений в английском режиме нет, а в словаре над списком сказано, что
  примеры употребления — предложения уроков — пока русские.
- **Сверки с учебниками.** Английский сделан с русского текста приложения и не
  сверен ни с Machen (1923), ни с Pratico & Van Pelt. Это первое издание того,
  что печатает приложение, а не перевод соответствующего английского учебника.
  Поэтому в настройках, в списке лицензий, есть отдельная запись: английский
  текст — неофициальный перевод, правообладатели его не составляли и не
  одобряли.
- **Остальных образцов для вычитки.** Здесь уроки 1–3 каждого курса; остальные
  переведены прямо в данных и в эту папку не выгружались.

## Как получены файлы

Не перепечатаны руками. Каждый файл собран скриптом, который берёт поле
`grammar` из данных и **заменяет только русские отрезки — те, что стоят между
словами изучаемого языка**. Поэтому ни одна огласовка и ни одно придыхание не
могли быть переставлены: это тот сбой, который в данных ловит
`tests/hebrew-content.test.js`, а в переводе заметить нечем — слово выглядит
одинаково и является другой строкой.

Проверка в сборке двухступенчатая:

1. в готовом файле не остаётся ни одной кириллической буквы;
2. каждое слово изучаемого языка в готовом файле **дословно встречается** в
   исходном уроке — посимвольно, с сохранением порядка знаков.

Второе и есть гарантия: слово здесь никто не набирал.

## Терминология

Термины не переведены буквально, а возвращены к общепринятым английским:

| Русское издание | Английский текст |
|---|---|
| бегадкефат | begadkefat |
| шва, немое / произносимое | shewa, silent / vocal |
| «слабый» / «сильный» дагеш | dagesh lene / dagesh forte |
| камец, камец хатуф | qamets, qamets hatuf |
| хатеф-патах | hateph patach |
| matres lectionis | matres lectionis |
| соединительные гласные | connecting vowels (thematische Vokale) |

Знаки произношения в греческом переведены в английскую традицию: в русском
издании `αυ` записано как «[ав]», `ευ` — «[эв]», `υι` — «[юй]»; в английском
тексте это `[au]`, `[eu]`, `[üi]`. Названия греческих букв оставлены греческими
(`άλφα`), как в данных: английские имена (alpha, beta…) — отдельное решение,
которого в источнике нет.

## Отступления от разметки

- Кнопка «Показать всё» (`alphabet-toggle`) в главу 1 иврита не перенесена: в
  документе она ничего не раскрывает. Сами таблицы, которые она раскрывает,
  стоят целиком.
- Нумерованные разделы — `##`, ненумерованные подписи вроде «Соединительные
  гласные» — `###`.

## Как продолжить

Сборка лежит в репозитории — `tools/en-build/`:

```bash
node tools/en-build/extract.js          # инвентарь русских отрезков -> inventory.json
node tools/en-build/build.js --check    # проверить, что всё сходится, ничего не писать
node tools/en-build/build.js            # собрать data/lessons.en.js и data/hebrew-lessons.en.js
node tools/en-build/markdown.js         # выгрузить читаемые образцы в эту папку
```

Для следующего урока в папку сборки добавляются только новые русские отрезки:
`greek-NN.map.json` (или `hebrew-NN.map.json`), строка в `titles-*.json` и
значения в `vocab-*.json`. Еврейский и греческий текст по-прежнему не набирается
руками: `build.js` сам вырезает слова изучаемого языка из русских данных, а потом
отказывается писать файл, если в результате осталась кириллица, если изменились
теги или если слово не встречается в исходном уроке дословно. Поэтому `--check`
перед коммитом обязателен.

В `inventory.json` (его пишет `extract.js`) — рабочий черновик, в репозиторий он
не попадает.

Подписи парадигм и чтение ивритского слова в эту папку не выгружаются: первые —
закрытый словарь терминов в `UI_EN` (`js/i18n.js`), второе срезается из самого
поля `translit` в момент отрисовки (`displayTranslit()`). Проверка обеих частей —
`tests/i18n.test.js`; он же падает, если в парадигме появится русская подпись,
которой нет в словаре.
