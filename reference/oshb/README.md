# OSHB, стихи для примеров употребления

Здесь лежат **только те стихи, которые показывает словарь** для слов, которых
пособие НББС ни разу не употребляет в обороте. Это не учебник и не текст для
чтения: приложение берёт отсюда `verses.json` через `data/hebrew-examples.js`,
и больше ничего.

## Что за текст

| | |
|---|---|
| Еврейский текст | Open Scriptures Hebrew Bible (OSHB), Westminster Leningrad Codex 4.20, файлы `wlc/*.xml` из <https://github.com/openscriptures/morphhb> |
| Огласовка и акценты | скопированы машинно, без нормализации и без ручного набора |
| Леммы | атрибут `lemma` в OSHB — номера Стронга; по ним стих и привязан к словарной статье |
| Русский перевод | Синодальный, общественное достояние; цифровая копия перевода — `SYNOD` с <https://bolls.life> |
| Лицензии | в `data/licenses.js` (OSHB и Синодальный перевод) |

## Как отобраны стихи

1. Для каждого слова из `data/hebrew-lessons.js` берётся номер Стронга по
   лемме. Сравнение — по согласным и огласовке с точностью до порядка знаков:
   OSHB и Strong's пишут один и тот же знак в разном порядке, а иногда
   расходятся в огласовке (`חֵסֵד` / `חֶסֶד`, `לַיִל` / `לַיְלָה`). Такие
   пары перечислены в правилах отбора явно; угадывать их нельзя.
2. Стих должен содержать слово с этой леммой, быть длиной 3–20 слов, а форма
   слова — иметь огласовку: в OSHB есть кетивы без огласовки (`ישבתי`), они
   не годятся для примера.
3. Часть речи сверяется по морфокоду OSHB (`HN…` существительное, `HV…`
   глагол, `HA…` прилагательное и т. д.): омоним вроде `חַיּוֹת` не должен
   представлять прилагательное `חַי`.
4. Русский стих обязан содержать основу одного из значений словарной статьи:
   иначе стих мог быть выбран по омониму (`שֵׁם` «имя» против «Сим»).
5. **Главы, где число стихов в Синодальном переводе не совпадает с OSHB,
   исключены**: в них нумерация расходится (Ис. 9, Мал., Иоиль). Псалтирь
   исключена целиком: в доступной копии перевода её главы смещены.
6. Из двух равных кандидатов выбирается более короткий стих, затем более
   ранний по канону. Пять слов (`יְרוּשָׁלִַם`, `חַי`, `קָטֹן`, `מְעַט`, `שֶׁמֶן`)
   получили стих вручную: автоматический выбор брал другую часть речи,
   переносное значение или арамейский стих вместо еврейского.

## Что здесь лежит

`verses.json` — 115 стихов, на которые ссылается `data/hebrew-examples.js`.
Поля: `osis` (например, `Gen.1.1`), `he` (стих из OSHB дословно), `ru`
(Синодальный перевод). Стихи отсортированы по канону.

## Чего здесь нет

- **Псалтири** — из-за расхождения нумерации глав в доступной копии перевода.
- **Служебных слов** `וְ`, `לְ`, `בְּ`, `כְּ`, `הֲ`, `עַל־דְּבַר` — в стихе
  они стоят приставкой или частью оборота, и подсветить их как отдельное
  слово нельзя. Эти шесть статей остаются без примера, и это правильный
  результат, а не пробел: пособие их в оборотах тоже не даёт.

## Правила правки

- **Не набирайте еврейский текст руками.** Порядок знаков огласовки невидим
  на экране; строка, выглядящая так же, может быть другой строкой. Текст
  берётся только машинно из OSHB.
- **Не правьте `verses.json` в одиночку.** `data/hebrew-examples.js`
  строится из него; расхождение поймает `tests/hebrew-content.test.js`.
- **Не «улучшайте» перевод.** Русский — Синодальный, как напечатан; если
  стих не подходит педагогически, выбирайте другой стих, а не переписывайте
  перевод.
